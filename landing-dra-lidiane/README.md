# Landing page da Dra. Lidiane

Página única em HTML com Tailwind CSS. Abra `index.html` no navegador.

- `index.html`: a página
- `assets/styles.css`: CSS já compilado
- `src/styles.css` + `tailwind.config.js`: fonte do Tailwind
- `images/`: ilustrações SVG provisórias (troque pelas fotos reais com os mesmos nomes)
- `tools/gerar-imagens.py`: gera de novo as ilustrações

Para compilar o CSS depois de mudar o HTML (na raiz do repositório):

```bash
npm install
npm run build:landing
```

Antes de publicar, troque o número `5500000000000` dos links do WhatsApp, o link do Instagram e os depoimentos de exemplo pelas avaliações reais.
